# 🐍 네온 지렁이 게임 (Neon Snake Game)

HTML5 Canvas와 Vanilla JavaScript로 제작된 웹 브라우저 기반 네온 지렁이 게임입니다.  
별도의 프로그램 설치나 외부 라이브러리 없이 웹 브라우저만 있으면 즉시 실행 가능합니다.

---

## ✨ 주요 기능
- **직관적인 조작**: 방향키, WASD, 마우스/터치 전용 온스크린 D-패드 지원
- **자체 내장 사운드**: Web Audio API를 활용하여 외부 파일 다운로드 없이 레트로 효과음(먹이 섭취, 보너스, 게임오버) 재생
- **최고 점수 저장**: `localStorage`를 통해 브라우저를 닫아도 최고 점수 유지
- **보너스 먹이 & 이펙트**: 주기적으로 생성되는 황금 먹이와 네온 파티클 효과
- **3단계 난이도**: 느림 / 보통 / 빠름 실시간 선택 가능

---

## 🎮 실행 방법
* `index.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)로 더블 클릭하여 실행합니다.
* GitHub Pages를 활성화하면 웹 링크로도 바로 배포하여 다른 사람과 공유할 수 있습니다.

## 🕹️ 조작 키 가이드
| 동작 | 키보드 키 | 온스크린 버튼 |
| :--- | :--- | :--- |
| **위로 이동** | `↑` 또는 `W` | `▲` |
| **아래로 이동** | `↓` 또는 `S` | `▼` |
| **왼쪽으로 이동** | `←` 또는 `A` | `◀` |
| **오른쪽으로 이동** | `→` 또는 `D` | `▶` |
| **일시정지 / 계속하기** | `Space` | `⏸️` / `●` |
